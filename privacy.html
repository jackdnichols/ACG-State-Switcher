Privacy Policy

ACG Utilities State Switcher is a browser extension for developer and QA workflows on ACG/AAA web properties.

Data collection

The extension does not collect, transmit, sell, or share personal data. It does not send browsing history, cookies, page content, custom ideas, or selected state information to any external server.

Local storage

The extension stores preferences locally in the browser, including popup theme, active tab, selected environment, badge settings, custom A/B test ideas entered by the user, and a temporary selected ACG state/ZIP override used to complete the state-switching workflow. These values remain in the browser unless removed by the user or browser.

Cookie access

The extension reads and writes only the cookies needed for its user-facing ACG state-switching feature, such as AEM.state, zipcode, and related ACG location cookies. Cookie access is used only to make the selected ACG state take effect in the current browser session.

Site Inspector

The Site Inspector tool fetches pages, images, and scripts from acg.aaa.com, meemic.com, and meemicfoundation.org (and their subdomains) that the user starts a scan against, so it can check for broken links/images, environment leaks, spelling issues, and search terms. This is hard-scoped in code to those three sites — no setting can make it fetch or send credentials to any other domain. Scan results stay in the browser tab and are only written to disk if the user clicks a CSV export button; nothing is transmitted to any external server.

Remote code

The extension does not load or execute remotely hosted code. Its functionality is contained in the submitted extension package.

Affiliation

This extension is not affiliated with AAA or its subsidiaries unless distributed by an authorized publisher.
